أتيليه — متجر أزياء إلكتروني متكامل (Supabase)
====================================================

الموقع متصل فعليًا بمشروع Supabase بتاعك:
https://hpaohnfxgbulfwsgwclu.supabase.co

قبل ما يشتغل الموقع، لازم تعملي 3 خطوات في لوحة Supabase:


الخطوة 1: إنشاء الجداول والصلاحيات
------------------------------------
1. ادخلي على supabase.com > مشروعك > SQL Editor > New query.
2. افتحي ملف sql/schema.sql من داخل هذا المجلد، انسخي محتواه كله، والصقيه في المحرر.
3. اضغطي Run.
   هذا هيعمل: جدول الأقسام، المنتجات، الأدمن، الطلبات، عناصر الطلبات،
   كل صلاحيات الحماية (RLS)، وباكت تخزين صور المنتجات، بالإضافة لأقسام
   تجريبية (نسائي / رجالي / إكسسوارات) تقدري تعدليها أو تحذفيها بعدين.


الخطوة 2: إنشاء حساب الأدمن
------------------------------------
1. من القائمة الجانبية: Authentication > Users > Add user > Create new user.
2. حطي إيميل وباسورد لحسابك كأدمن (واحفظيهم كويس).
3. انسخي الـ "User UID" بتاع الحساب اللي عملتيه (هتلاقيه في نفس الصفحة).
4. ارجعي لـ SQL Editor وشغّلي الأمر ده بعد ما تستبدلي القيم:

   insert into public.admins (user_id, full_name)
   values ('الصقي-الـ-UID-هنا', 'اسمك');

بكده الحساب ده بقى أدمن، ويقدر يدخل لوحة التحكم ويتحكم في كل حاجة.
(تقدري تضيفي أكتر من أدمن بنفس الطريقة لأي حساب تاني.)


الخطوة 3: تشغيل الموقع
------------------------------------
الموقع HTML/CSS/JS عادي بدون أي أدوات بناء (بدون npm)، فتقدري:

أ) تجربة سريعة محليًا:
   - افتحي index.html مباشرة في المتصفح، أو شغّلي سيرفر بسيط:
     python3 -m http.server 8000
   ثم افتحي: http://localhost:8000

ب) نشر الموقع أونلاين (الأفضل، عشان يبقى فعليًا "أونلاين"):
   ارفعي المجلد كله كما هو إلى أي استضافة ملفات ثابتة، مثل:
   - Netlify: اسحبي المجلد وأفلتيه في netlify.com/drop
   - Vercel
   - Cloudflare Pages
   - GitHub Pages

   بعد الرفع هيبقى عندك رابط عام يفتح للزوار، ورابط لوحة التحكم هيكون:
   yourdomain.com/admin/login.html


رابط لوحة التحكم:
------------------------------------
admin/login.html
سجّلي دخول بالإيميل والباسورد اللي عملتيهم في الخطوة 2.


مميزات لوحة التحكم:
------------------------------------
- نظرة عامة: عدد المنتجات/الأقسام/الطلبات وآخر الطلبات.
- الأقسام: إضافة / تعديل / حذف أقسام، وتفعيل أو إيقاف أي قسم.
- المنتجات: إضافة / تعديل / حذف منتجات، رفع صورة مباشرة (بتترفع لتخزين
  Supabase تلقائيًا)، تحديد السعر وسعر ما قبل الخصم، المخزون، المقاسات
  والألوان (كتابة حرة، مفصولة بفاصلة)، تفعيل/إيقاف المنتج، وتمييزه.
- الطلبات: عرض كل الطلبات الواردة من الموقع، تفاصيل كل طلب (المنتجات،
  الكمية، العنوان، رقم الهاتف)، وتغيير حالة الطلب (قيد المراجعة /
  قيد التجهيز / تم الشحن / تم التسليم / ملغي).


مميزات الموقع للزوار:
------------------------------------
- عرض المنتجات مقسّمة حسب الأقسام، مع فلترة سريعة.
- صفحة تفاصيل كل منتج (صورة، وصف، سعر، اختيار مقاس/لون، كمية).
- سلة مشتريات تتحفظ في المتصفح حتى لو الزائر قفل الصفحة.
- إتمام الطلب مباشرة (اسم، هاتف، عنوان، ملاحظات) وحفظه في قاعدة البيانات
  فورًا مع رقم طلب مميز يظهر للعميل كتأكيد.


تخصيص الشكل والاسم:
------------------------------------
- اسم المتجر: غيّري قيمة STORE_NAME في js/config.js.
- الألوان والخطوط: من أول أسطر css/style.css (متجر) و css/admin.css (إدارة)
  تحت متغيرات :root — غيّري قيم --accent و --gold وغيرها زي ما تحبي.
- شعار/نصوص الصفحة الرئيسية: من داخل index.html، قسم <section class="hero">.


بنية الملفات:
------------------------------------
index.html              الصفحة الرئيسية للمتجر
css/style.css            تصميم المتجر
js/config.js             مفاتيح الاتصال بـ Supabase (لا تشاركيها مع مصادر غير موثوقة لو غيّرتيها)
js/store.js               منطق المتجر (منتجات، سلة، طلب)
admin/login.html          صفحة دخول الأدمن
admin/dashboard.html      لوحة التحكم
css/admin.css              تصميم لوحة التحكم
js/admin-auth.js           منطق تسجيل الدخول والتحقق من صلاحية الأدمن
js/admin-dashboard.js      منطق لوحة التحكم بالكامل (كل الـ CRUD)
sql/schema.sql              كل أوامر قاعدة البيانات والصلاحيات
